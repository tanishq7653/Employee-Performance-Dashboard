# Attrition & Employee Performance Dashboard

## Project Overview
This project analyzes employee attrition and performance using Python, Pandas, NumPy, SQL, Excel, and Power BI.

## Dataset
- 2,000 employee records
- Department and Job Role
- Age, Gender, Education
- Job Level and Years at Company
- Monthly Salary
- Job Satisfaction
- Work-Life Balance
- Performance Score
- Training Hours
- Distance From Home
- Overtime
- Attrition

## Tools Used

### Python — Analysis
Python was used for data cleaning, exploratory data analysis, feature engineering, and identifying patterns.

### Pandas — Data Manipulation
Used for cleaning, grouping, aggregation, missing-value handling, and feature engineering.

### NumPy — Computation
Used for numerical calculations and dataset preparation.

### SQL / MySQL — Querying
Used for business analysis, department attrition, tenure analysis, satisfaction, overtime, and high-risk segments.

### Excel — Validation
Used for initial data inspection and validation.

### Power BI — Visualization
Used to create the interactive HR dashboard, KPI cards, charts, and slicers.

### DAX — Calculations
Used to create dynamic KPIs such as Total Employees, Total Attrition, Attrition Rate, Average Salary, and Average Performance.

### 1. Executive Overview

## Project Workflow
Raw Data → Excel → Python → SQL → Power BI + DAX → Business Insights

## Key Business Questions
1. What is the overall attrition rate?
2. Which departments have the highest attrition?
3. Which tenure group has the highest turnover?
4. Does overtime relate to attrition?
5. Does satisfaction affect attrition?
6. Does work-life balance affect attrition?
7. Does salary relate to turnover?
8. Does distance from home relate to attrition?
9. How does performance vary by department?
10. Is training associated with performance?

## Key Insight
The portfolio dataset is designed to show a concentration of attrition among employees with 1–3 years of tenure.

**Note:** This is a synthetic portfolio dataset. Findings should not be presented as results from a real company.
